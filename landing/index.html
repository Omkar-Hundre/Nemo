SCHEMA & QUERY SAFETY

Database Introspection

Inspect SQLite and SQL database structures, audit foreign keys, check column indices, and test read queries with built-in mutation locks.

01 / SCHEMA DISCOVERY

Table Architecture

Scans tables, columns, data types, constraints, and index definitions in milliseconds without locking production writes.

PRAGMA table_info(users);
PRAGMA foreign_key_list(events);
02 / QUERY VERIFICATION

Read-Only Safety Lock

Blocks destructive statements (DROP, TRUNCATE, DELETE without WHERE) automatically before execution touches disk.

SELECT COUNT(*) FROM deployments
WHERE status = 'verified';
